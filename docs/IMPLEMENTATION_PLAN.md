# Implementation plan

1. Foundation: documentation, Next.js strict configuration, RTL tokens and layout.
2. Data and identity: Supabase schema, RLS, seed library, authentication routes.
3. Core domain: cycle calculations, validation, profiles and cycle entry.
4. Guidance: dashboard, phase detail, DEVI and frame presentation.
5. Personalization: daily check-ins, deterministic ranking, feedback.
6. History: calendar, history, editing and correction feedback.
7. Privacy and offline: privacy mode, exports, deletion, manifest and safe service worker.
8. Quality: unit/component/E2E coverage, accessibility/security checks, lint, types, and production build.

Each phase is validated before continuing. Deployment and merging remain explicitly out of scope for this branch.
